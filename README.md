# 📚 考研情侣打卡PK系统

> 暑期考研情侣专属打卡互动系统 - 和TA一起努力，共同进步！

## ✨ 功能

- ✅ **每日打卡** - 记录数学1、英语1、政治、408 各科学习时长
- 📝 **背单词追踪** - 记录每日单词背诵数量
- 📊 **实时进度对比** - 双方学习进度一目了然
- 📸 **截图上传** - 上传学习时长证明
- 🏆 **每日PK** - 自动计算得分，比拼学习成果
- 📈 **历史战绩** - 查看PK胜负记录和趋势
- 🔄 **自动刷新** - 每10秒自动更新数据

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 初始化数据库

```bash
npm run db:generate
npm run db:push
```

### 3. 设置用户信息

```bash
node setup.js
```

按照提示输入你和女朋友的昵称、选择头像。

### 4. 启动应用

```bash
npm run dev
```

打开浏览器访问: **http://localhost:3000**

## 🎯 计分规则

| 项目 | 计分方式 |
|------|---------|
| 数学1 | 1小时 = 10分 |
| 英语1 | 1小时 = 10分 |
| 政治 | 1小时 = 10分 |
| 408 | 1小时 = 10分 |
| 背单词 | 1个 = 1分 |

**每日总分 = 各科得分 + 单词得分**

## 📱 页面说明

- **今日** - 首页看板，显示双方今日学习进度和PK比分
- **打卡** - 填写学习数据，上传截图
- **PK** - 历史对战记录和总战绩
- **历史** - 查看过往学习记录

## 🛠️ 技术栈

- Next.js 14 (App Router)
- Prisma + SQLite
- Tailwind CSS
- 北京时间时区

## 💡 提示

- 数据存储在 `prisma/dev.db` 文件中，备份此文件即可备份所有数据
- 截图存储在 `public/uploads/` 目录下
- 如需修改用户信息，重新运行 `node setup.js` 即可
